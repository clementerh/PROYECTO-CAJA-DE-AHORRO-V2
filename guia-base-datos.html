2. Rangos y Salarios

Los rangos docentes con su salario base. Al editar el salario de un rango, automáticamente se actualiza para todos los afiliados con ese rango.

💰 sueldo_base

ADMIN. RANGOS
CampoTipoClaveDescripción
id_sueldoINT AUTO_INCREMENTPKIdentificador del rango
descripcionVARCHAR(100)UKNombre del rango: Instructor, Asistente, Agregado, Asociado, Titular
montoDECIMAL(12,2)Salario base en Bs. (se comparte para todos los docentes del mismo rango)

⚠️ Regla clave: Como cada afiliado tiene un FK (id_sueldo) que apunta aquí, cuando se modifica el monto de un rango, el sistema usa siempre el valor actualizado. No se necesita recorrer afiliados — la relación FK lo resuelve automáticamente.

4. Préstamos

El módulo más importante. Se calcula TODO al aprobar: cuotas, fechas, montos. Sin recálculos nunca. El saldo final siempre es 0,00 Bs.

🔑 Regla del 33,33%: Antes de aprobar, el sistema verifica que monto_cuota ≤ 33,33% del sueldo_base del afiliado. Si no alcanza, no se permite aprobar el préstamo.

7. ¿Cómo funciona todo junto?

📝 Otorgar un préstamo

  1. Secretaria busca al afiliado por cédula
  2. Sistema muestra datos + rango + sueldo base
  3. Calcula 33,33% del sueldo = máximo de cuota
  4. Secretaria ingresa monto y número de cuotas
  5. Sistema calcula cuota mensual con tasa 8%
  6. Si cuota ≤ 33,33% → se puede aprobar
  7. Se guarda en prestamo
  8. Se genera automáticamente el plan_pago completo
  9. Saldo final de última cuota = 0,00 Bs.

💸 Registrar un abono

  1. Asociado viene presencialmente
  2. Se busca por cédula → se ven sus préstamos
  3. Se ve el plan de pago con cuotas pagadas/pendientes
  4. Se registra el pago en detalles_prestamo
  5. Se marca la cuota como pagada en plan_pago
  6. Si es abono extra → se marcan cuotas del final
  7. Cuando todas las cuotas estén pagadas → estado = 'pagado'

📄 Exportar PDF personal

  1. Secretaria ingresa cédula del afiliado
  2. Sistema consulta v_prestamos_completo
  3. Muestra historial de TODOS los préstamos
  4. Incluye plan de pago de cada uno
  5. Se puede exportar individual o completo
  6. PDF con: datos personales, cuotas, saldos, fechas

📊 Exportar PDF general

  1. Secretaria selecciona mes y tipo de reporte
  2. Sistema consulta v_prestamos_por_mes
  3. Muestra: cuántos préstamos, cuántas personas, montos
  4. Incluye cédula, datos y monto de cada uno
  5. Se genera PDF con balance del mes
  6. Útil para balances trimestrales y auditoría anual
